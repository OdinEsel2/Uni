# Contributing 🙌

Thanks for helping! This guide is only as good as the people who add to it.
**You do not need to know how to code.** If you can edit a text box, you can contribute.

## The easiest way (no Git needed)

1. Find the file you want to improve (e.g. a university in [`universities/`](universities/)).
2. Click the **pencil ✏️ icon** in the top-right of the file on GitHub.
3. Make your changes.
4. Scroll down, write a short note about what you changed, and click **"Propose changes"**.
5. Click **"Create pull request"**. Done — a maintainer will review it.

## Adding a new university

1. Copy `universities/_template.md`.
2. Rename it, e.g. `universities/university-of-sydney.md`.
3. Fill in the sections and open a pull request.

## Adding a tip, scholarship, or deadline

Same idea — add to the relevant folder, or just [open an issue](../../issues/new/choose) and we'll add it.

## Ground rules

- ✅ **Cite official sources** (link the uni/UAC page) — accuracy matters most.
- ✅ Keep personal statements **anonymised** — never include someone's name or details without permission.
- ✅ Be kind and constructive (see [Code of Conduct](CODE_OF_CONDUCT.md)).
- ❌ No spam, referral links, or paid "essay writing" promotions.

## Not sure?

Open an issue with your question — no question is too small. 💬
