# 🎓 Uni Applications — an open, community-built guide

A free, crowd-sourced guide to applying for university — written by students, for students.
Deadlines, course info, scholarship leads, and real personal-statement tips, all in one place.

> Starting with **Australia (UAC / NSW)**, but built to grow to any country. Add yours!

## What's inside

| Folder | What goes here |
|--------|----------------|
| [`universities/`](universities/) | One file per uni: courses, ATAR/entry info, key links |
| [`personal-statements/`](personal-statements/) | Tips, structure, and anonymised example statements |
| [`scholarships/`](scholarships/) | Scholarships + bursaries worth knowing about |
| [`deadlines/`](deadlines/) | Key application dates (UAC, early entry, etc.) |
| [`resources/`](resources/) | Useful tools, links, and reading |

## How to use it

Browse the folders above, or jump to [deadlines](deadlines/) if you're in a hurry.
Spotted something out of date or missing? **Please fix it** — see [CONTRIBUTING](CONTRIBUTING.md).

## Contributing

Anyone can help — you don't need to be a coder. You can:
- ✏️ **Edit a file** straight on GitHub (pencil icon → make changes → "Propose changes")
- 🆕 **Open an issue** to suggest something ([New issue](../../issues/new/choose))
- 🔀 **Open a pull request** with your additions

Full guide: [CONTRIBUTING.md](CONTRIBUTING.md) · Please also read the [Code of Conduct](CODE_OF_CONDUCT.md).
